# Knowledge Engine

The Knowledge Engine transforms memories into structured knowledge.

## Pipeline

```text
Memory
   │
   ▼
Knowledge Extraction
   │
   ▼
Knowledge Consolidation
   │
   ▼
Knowledge Graph
   │
   ▼
Inference
   │
   ▼
Conflict Detection
   │
   ▼
Resolution
```

## Modules

### Extractor

Extracts entities and relations from memories.

### Consolidator

Merges duplicated knowledge.

### Graph

Stores entities and relationships.

### Inference

Generates new knowledge through graph traversal.

### Explanation

Explains why an inference was generated.

### Conflict Resolution

Detects contradictory facts and decides which knowledge should be preserved.

### Relearning

Updates knowledge confidence according to new evidence.
